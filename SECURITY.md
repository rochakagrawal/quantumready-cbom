# Security

This repository contains a JSON profile, an example CBOM and a validator. It does not
contain the QuantumReady scanner, customer data or credentials.

If you find a security issue in the validator or in the published example, please do not
open a public issue. Email the address on https://getquantumready.app/contact and include:

- what you found,
- the smallest input that reproduces it,
- the version or commit you tested.

We will acknowledge receipt and tell you whether the issue affects the hosted service.

For a vulnerability in the hosted service, use the same contact and state that it is a
security report. Please do not test against systems you do not own.
